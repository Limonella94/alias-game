# Alias

Игра «Alias» (Элиас) для Android: объясни слово, не называя его.
Тёмное фэнтези-оформление, темы слов, детский режим, обновления прямо из приложения.

## Установка

1. Откройте на телефоне ссылку и скачайте APK:
   **https://github.com/Limonella94/alias-game/releases/download/latest/alias.apk**
2. Разрешите установку из браузера, если телефон спросит, и установите.

Дальше приложение обновляется само: при запуске проверяет новую версию и показывает баннер
«Доступна новая версия» → **Обновить** → **Установить**.

## Что умеет (v0.4)

**Обычная игра**
- 2–6 команд, игроки в командах — приложение само ведёт очередь объясняющих («Объясняет: Маша»).
- Настройки: время раунда, очки до победы, сложность слов (лёгкие / средние / сложные), штраф за пропуск.
- Последнее слово: сгорает / любая команда / своя команда без ограничения времени.
- Темы, выбор плитками, у каждой — обложка: «Базовый» (318 слов), «Гарри Поттер» (84), «Ведьмак» (74),
  «Эрудит» (246), «Только для взрослых» 18+ (235), «IT и гики» (237), «Киноман» (232), «Назад в 90-е и 2000-е» (230).
- Раунд: таймер, свайп вверх/вниз или кнопки, пауза и автопауза при сворачивании, звуки и вибрация.
- Итоги раунда с исправлением отметок, таблица счёта, экран победителя, «Реванш».

**Детский режим** (картинки-эмодзи, 160 слов)
- «Малыши 3–5» — объясняет взрослый, без таймера и штрафов, огромные кнопки, итог «Мы угадали N!».
- «Детки 5–6» — объясняют сами по картинке, таймер 90 сек, все вместе или две команды.

**Удобства**
- Настройки запоминаются между запусками.
- Незаконченную игру можно продолжить с главного экрана — даже после перезапуска телефона.
- Слова не повторяются между играми, пока не закончатся новые; историю можно сбросить.

## Как идёт разработка

- Код пишется в `main`; после каждого push GitHub Actions гоняет тесты, собирает APK и выкладывает его
  в релиз `latest` вместе с `version.json` — по нему приложение и находит обновления.
- Номер версии = число коммитов, поэтому каждая сборка новее предыдущей.
- APK подписывается ключом из секретов репозитория — обновление поверх может выпустить только владелец.

### Сборка у себя

1. Android Studio → **File → New → Project from Version Control** → ссылка на репозиторий → **Clone**.
2. Дождаться **Gradle Sync**. Если Studio предложит обновить Gradle/AGP — **отказаться**.
3. Выбрать телефон → **▶ Run**.

Локальная сборка подписана другим ключом: поверх версии с GitHub она не встанет (и наоборот).

## Устройство проекта

```
app/src/main/java/ru/limonella/alias/
├── core/              чистый Kotlin, без Android (покрыт unit-тестами)
│   ├── model/         Word, WordPack, Team, RuleSet, GameConfig, WordFilter, KidsPresets
│   ├── engine/        GameEngine — все правила игры, WordDeck, GameState
│   └── sound/         интерфейс звуков
├── data/
│   ├── words/         темы и слова из assets
│   ├── storage/       DataStore (значения как JSON)
│   ├── settings/      сохранённые настройки
│   ├── session/       передача игры между экранами, автосохранение
│   ├── history/       история показанных слов
│   ├── sound/         звуки (SoundPool)
│   └── update/        проверка и установка обновлений
├── di/                AppContainer — создание зависимостей
├── feature/           экраны: home, setup, themes, game, kids
└── ui/                тема (палитра, шрифты), общие компоненты, навигация

app/src/main/assets/words/    темы (JSON) — новая тема = новый файл
app/src/main/assets/covers/   обложки тем
app/src/main/res/drawable-nodpi/   фоны, иллюстрации, иконка
```

Подробные заметки для разработки — в [CLAUDE.md](CLAUDE.md).
