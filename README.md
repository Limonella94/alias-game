# Alias

Игра «Alias» (Элиас) для Android: объясни слово, не называя его.

## Как запустить

1. Android Studio → **File → New → Project from Version Control** → ссылка на этот репозиторий → **Clone**.
2. Дождаться окончания **Gradle Sync** (первый раз — несколько минут).
   Если Studio предложит установить недостающий Android SDK — согласиться.
   Если предложит обновить Gradle/AGP — **отказаться** (версии подобраны совместимыми).
3. Выбрать телефон в списке устройств → **▶ Run**.

Обновить код после изменений: **Git → Pull** (Ctrl+T), затем снова **▶ Run**.

## Что уже есть (v0.4)

- Меню: взрослая игра и детский режим (пока заглушка).
- Настройки: 2–6 команд, время раунда, очки до победы, сложность слов, штраф за пропуск, «последнее слово для всех».
- Раунд: таймер, свайп вверх/вниз или кнопки, пауза (и автопауза при сворачивании).
- Итоги раунда с исправлением отметок, таблица счёта, экран победителя.
- Темы с выбором: «Базовый» (318 слов), «Гарри Поттер» (84), «Ведьмак» (74).
- Последнее слово: сгорает / любая команда / своя команда без ограничения времени.
- Игроки в командах: приложение само ведёт очередь объясняющих.
- Настройки запоминаются между запусками.
- Незаконченную игру можно продолжить с главного экрана (даже после перезапуска телефона).
- Слова не повторяются между играми, пока не закончатся новые; историю можно сбросить.
- Обновление прямо из приложения (баннер на главном экране).
- Детский режим на картинках-эмодзи: «Малыши 3–5» (объясняет взрослый, без таймера) и «Детки 5–6».
- Звуки: угадано, пропуск, отсчёт последних секунд, конец времени (можно выключить).

## Архитектура

```
app/src/main/java/ru/limonella/alias/
├── core/            чистый Kotlin, без Android
│   ├── model/       Word, Team, RuleSet, GameConfig, WordFilter
│   └── engine/      GameEngine (правила игры), WordDeck, GameState
├── data/
│   ├── words/       WordRepository + чтение наборов слов из assets
│   └── session/     передача настроек между экранами
├── di/              AppContainer — создание зависимостей
├── feature/         экраны: home, setup, game, kids
└── ui/              тема и навигация
app/src/main/assets/words/   наборы слов (JSON)
```
